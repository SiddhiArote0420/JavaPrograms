## 🚀 How to Compile and Run Any Program

Make sure you have **JDK (Java Development Kit)** installed on your system.

```bash
# 1. Clone the repository
git clone https://github.com/SiddhiArote0420/JavaPrograms.git

# 2. Navigate to any topic folder
cd JavaPrograms/05-Arrays

# 3. Compile and run a Java file
javac ArrayMerge.java
java ArrayMerge
```
